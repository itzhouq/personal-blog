想了很久，决定把"做东西"这件事本身公开出来。这就是 Build in Public——边做边说，把过程当产品。

## 为什么是现在

过去我习惯闷头做事：学一个技术、写一个脚本、搭一个服务，做完就完了，没有沉淀，也没有反馈。结果就是：

- 同样的坑踩了两遍，因为上一次的笔记随手丢在了聊天记录里；
- 做出来的东西没人知道，也就没人用、没人提意见；
- 没有外部压力，很多"想做"的事情最后都变成了"想过的"事情。

公开，是这三个问题的共同解法。

## 我打算公开什么

1. **技术踩坑实录**：比如怎么把聚合了全网免费额度的大模型网关跑起来，这类文章对同路人是真有用的。
2. **产品构建过程**：我会在本站陆续挂上自己的小工具，从选型、写代码到上线的数据，全部记录。
3. **变现尝试**：包括但不限于 API 服务、工具订阅、返利合作。赚到多少、亏掉多少，都摊开说。

## 这个网站的路线图

- ✅ 个人博客网站（你正在看的这个）
- 🚧 每周一篇 build in public 记录
- ✅ 第一个挂载的小工具（AI Chat 游乐场）
- 🚧 更多小工具

## 写在最后

Build in public 最大的好处不是涨粉，而是**倒逼自己把事情做完**。当一周的进展要在下周公之于众时，拖延就变得很昂贵。

如果你也在做类似的事，欢迎通过 [GitHub](https://github.com) 或 RSS 订阅找到我，我们一起把事情做完。
