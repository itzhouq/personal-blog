写文章的人都有一个共同的噩梦：**图裂了**。

早年在论坛发的帖子，配图十有八九已经变成裂图图标——免费图床停服的、清理文件的、加防盗链的，图还活着但就是不给你看。更别提一些公共图床会压缩你的图、扫描你的内容，甚至悄悄关停。数据在别人手里，就没有安全感。

这次搭博客之后决心彻底解决：自己搭图床。方案是 **Cloudflare R2 + PicGo**，全过程不到半小时，成本为零。这篇是完整复盘。

## 为什么选 R2

对象存储的选择不少，我把主流方案拉了个表：

| 方案 | 免费额度 | 出站流量费 | CDN | 数据可控 |
|---|---|---|---|---|
| **Cloudflare R2** | 10GB 存储 + 千万级请求 | **永远免费** | 全球 CDN | 完全 |
| 阿里云 OSS | 无 | 按量计费 | 需额外购买 | 完全 |
| GitHub + jsDelivr | 仓库 1GB 软限 | 免费 | 有 | 依赖公开仓库 |
| SM.MS / Imgur 等 | 有限 | 免费 | 有 | 不可控 |

R2 的杀手锏就一条：**出站流量零收费**。图片这种东西，万一哪篇爆火，访问量是不可预测的——S3 / OSS 的出站流量费能让你体会什么叫"流量是福报也是账单"，而 R2 的出站流量无论多少都不收钱。加上每月 10GB 免费存储和千万级的请求额度，个人图床基本不可能用出账单来。

## 搭建四步

### 1. 创建存储桶

Cloudflare Dashboard → R2 对象存储 → 创建存储桶（首次使用需绑一张信用卡做身份验证，不扣费）。名字随意，比如 `pic`。

### 2. 绑定自定义域名

进入桶的设置 → 自定义域 → 连接域，填一个子域名比如 `pic.itzhouq.cn`，Cloudflare 自动配好 DNS 和 SSL。

这一步强烈建议做：R2 默认的 `r2.dev` 公开域名有请求频率限制，正式使用一定要走自定义域名。配好后访问这个域名，看到一个 XML 报错页（桶还是空的）就说明通了。

### 3. 生成 API 令牌

R2 概览页 → 管理 R2 API 令牌 → 创建：权限选"对象读和写"，**只指定这一个桶**（最小权限原则）。创建后拿到 Access Key ID、Secret Access Key 和 S3 端点——Secret 只显示一次，立刻保存好。

### 4. 配置 PicGo

[PicGo](https://github.com/Molunerfinn/PicGo) 是开源图床上传客户端（macOS/Windows/Linux 都有）。装好后到插件设置里搜 `s3`，装 picgo-plugin-s3，然后到图床设置里填：

- 应用密钥 ID / 应用密钥：上一步的两个 Key
- 桶名：`pic`
- 自定义节点：你的 S3 端点
- 自定义域名：`https://pic.itzhouq.cn`

设为默认图床，拖一张图进去测试，返回 `https://pic.itzhouq.cn/xxx.png` 且浏览器能打开——搞定。

## 最好用的部分：命令行上传

PicGo 常驻后台时会开放一个本地 HTTP API（端口 36677），这意味着图片上传可以变成一条命令，嵌进任何工作流：

```bash
curl --location --request POST 'http://127.0.0.1:36677/upload' \
--data-raw '{
    "list": ["/path/to/image.png"]
}'
```

返回：

```json
{"success":true,"result":["https://pic.itzhouq.cn/image.png"]}
```

对我这种让 AI Agent 帮忙写文章的人，这简直是量身定做：Agent 生成一张配图，脚本调这个接口上传，拿到外链直接写进 Markdown——全自动。

写作工具也能接：Typora 在偏好设置里选 PicGo (app) 上传服务，粘贴图片自动上传替换链接；Obsidian 装 Image Auto Upload Plugin，同样的事。

## 两个小坑

1. **重名覆盖**：上传路径默认保留原文件名，桶里同名文件会被覆盖。我现在的习惯是上传前给文件名加日期前缀（`2026-10-09-xxx.png`），或者用 PicGo 路径模板里的 `{timestamp}`。
2. **DNS 解析**：个别网络环境下自定义域名不生效，检查一下 Cloudflare 的 DNS 设置里该记录是否正常代理（橙色云开启）。

## 算一笔账

按一个月写 20 篇文章、每篇 10 张图、每张 500KB 算：存储累计 100MB/月，上传请求 200 次，访问就算爆了也就几万次 Class B 请求、10GB 出站流量——全部落在免费额度内，**账单 0 元**。按这个强度，10GB 存储空间要用满大约需要 8 年，届时超出的部分也才 $0.015/GB。

一次配置，图库钥匙从此在自己手里。如果你还在用说停就停的公共图床，值得花这半小时。
