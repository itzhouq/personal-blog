我的全部线上资产：一个博客、一个 14 个工具的工具箱、几个游戏攻略站、若干 API 服务——没有任何一台服务器。除了域名每年几十块钱，运行成本是 0 元。

不是我有什么黑科技，而是这些全部跑在 Cloudflare 的免费套餐上。这几年独立开发下来，我已经把"部署"这件事的成本压到了极限，而且事实证明：对于个人开发者能写出来的几乎所有东西，这套免费架构不但够用，还比买服务器更快、更稳、更省心。

所以我决定开一个新系列：**独立开发穷鬼套餐**。把我知道的全部讲出来——每篇都从我自己的真实项目讲起，不写纸面教程。这是开篇，先给你一张完整的地图。

> 声明：本系列与 Cloudflare 官方无任何关系，属于个人经验分享。文中提到的免费额度均标注核验日期，以[官方定价页](https://developers.cloudflare.com/platform/pricing/)为准。

## 先回答一个质疑：免费的东西能用吗

可以。Cloudflare 不是什么小公司——它是全球最大的 CDN 厂商之一，在全球三百多个数据中心提供边缘计算。它的免费套餐不是为了引流做的噱头，而是真实的商业策略：免费吸引用户，等你规模大了再付费。而个人开发者的规模，几乎永远到不了它的付费线。

几个关键数字（核验于 2026-10）：

| 服务 | 免费额度 | 能干什么 |
|---|---|---|
| Pages | 站点数量不限、带宽不限、每月 500 次构建 | 前端静态托管，你的博客、工具站、落地页全放这 |
| Workers | 10 万次请求/天 | Serverless 后端 API，个人项目根本用不完 |
| R2 | 10 GB 存储 + 出口流量免费 | 图床、文件存储，流量再大也不收带宽费 |
| D1 | 5 GB SQLite 数据库 | 关系型数据库，存用户数据、业务数据 |
| KV | 1 GB 存储、10 万次读/天 | 缓存、配置、轻量状态 |
| Tunnel | 免费 | 把家里的 NAS、本地服务安全暴露到公网 |
| Email Routing | 免费 | 用你自己的域名收邮件 |
| Workers AI | 每天有免费推理额度 | 跑 AI 推理，做简单的 AI 功能 |
| Web Analytics | 免费、不侵入 | 网站访问统计 |
| Turnstile | 免费 | 验证码，防机器人 |

翻译成人话：DNS、建站、后端 API、数据库、文件存储、内网穿透、收件邮箱、AI 推理、统计分析、人机验证——独立开发者需要的整条链路，一家全包了，不要钱。

## 我自己的架构长什么样

以这个博客和[工具箱](https://tools.itzhouq.cn)为例，一次完整的请求是这样的：

- **前端**：Next.js 静态导出，扔给 Pages。推一次代码，Cloudflare 自动构建、自动上 CDN、自动 HTTPS。
- **后端**：需要 API 的地方用 Workers 写几十行代码，或者 Pages 自带的 Functions。
- **数据**：不存用户数据的工具（我的工具箱就是）连数据库都不需要；需要的地方 D1 存结构化数据，KV 做缓存。
- **域名**：DNS 托管在 Cloudflare，解析免费、CDN 加速免费、DDoS 防护免费。

运维成本呢？没有运维。没有服务器要打补丁，没有磁盘要监控，没有证书要续期。凌晨三点不会被服务器告警叫醒——因为根本没有服务器。

## 但是，坑也是真实存在的

如果一切都丝滑，这个系列就没必要写了。这几年我踩过的坑，随便数数：

1. **构建配置劝退**：Pages 的构建命令、输出目录、环境变量，第一次配错就是连环报错，报错信息还不好懂。
2. **额度陷阱**：D1 的"500 万行读取/天"是按**扫描行数**算的，不是返回行数。一条没走索引的查询在几万行的表上跑一遍，额度就烧掉一大块。KV 每天只能写 1000 次，拿它当计数器用会当场去世。
3. **授权一头雾水**：想让命令行工具或者 AI 替你部署，得创建 API Token——但权限怎么给？给多了是安全隐患，给少了部署报错。官方文档讲得很全，但"第一次做"的路径很长。
4. **AI 时代的新问题**：现在很多人用 AI 写完整个项目，然后卡在最后一步——"怎么让它上线"。让 AI Agent 替你部署，授权和安全感怎么解决？这块市面上几乎没有中文教程。

这些坑，每一篇我都会写清楚"为什么"和"怎么办"，而不是只贴步骤。

## 这个系列会讲什么

按顺序（每周五更新，和我的 build in public 复盘文交替）：

1. **开篇**（本篇）：全家桶地图，我的 0 元架构。
2. **5 分钟部署**：写好的静态站怎么上 Pages——Git 连接和 wrangler 直传两条路，各自适合什么场景。
3. **Workers 第一个 API**：CORS 代理、定时任务，几十行代码能解决多少事。
4. **数据存哪**：KV / D1 / R2 怎么选，配额陷阱避坑清单。
5. **R2 图床实战**：白嫖一个自己的图床，引用社区现成的开源方案。
6. **让 AI 替你部署**：Agent + wrangler 的工作流，我真实的实操过程。
7. **Token 与授权安全**：最小权限模板，给 AI 也能放心给的 token。
8. **域名省钱链路**：首年低价注册 + Cloudflare 成本价续费的组合拳。
9. **Tunnel**：把家里的服务安全地暴露出去，不开端口不买公网 IP。
10. **阶段复盘**：我全部站点的成本表，以及 Pages 向 Workers 演进的趋势（这是 2026 年 Cloudflare 生态最重要的变化之一）。
