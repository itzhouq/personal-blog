最近身边失业的程序员同事越来越多了。前同事在群里发「有没有内推」，我顺手把 Boss 上几个岗位链接转给他，转到第三条发现自己卡住了：**岗位太多了，但真的适合他的没几个**。薪资对不上、要求对不上，还有一半是外包公司——他不缺岗位链接，缺的是「哪些值得投」。

再往后我就有点兔死狐悲了。我这也 10 年后端了，人在上海，上有老下有小，行业的消息一天比一天冷。焦虑解决不了问题，但数据可以——**与其猜市场怎么样，不如直接把市场扫一遍**。

于是花了一晚上，给自己写了个岗位采集器。这篇就是第一轮扫描的结果，先说结论，再讲怎么做的。

## 数据先说话

用 Chrome 调试协议复用自己登录过的浏览器，扫了 Boss直聘上海站 4 个关键词（AI Agent / 后端 / Go / Java）各前 2 页，共 120 个在招岗位。薪资取区间中点统计：

| 关键词 | 岗位数 | 薪资中位 | 25%-75% 分位 |
|---|---|---|---|
| **AI Agent** | 30 | **30K** | 25-40K |
| 后端 | 30 | 24K | 14-35K |
| Go | 30 | 20K | 13-26K |
| Java | 30 | **17K** | 14-26K |

先声明：这是搜索首页的样本，有平台算法偏好在里面，样本也不算大，**看趋势别当普查**。但有几个数字，够反直觉了。

## 三个反直觉的发现

**第一个：AI Agent 岗位不是虚火，是真给钱。** 中位 30K，比 Java 岗高 76%，比泛后端高 25%。我原本以为这类岗位会是一小撮高薪 Offer 拉平均值，结果 25%-75% 分位落在 25-40K——溢价是普遍性的，不是个例。

**第二个：AI Agent 岗的底座，还是 Java 那套。** 把 120 个岗位的技能词拉出来数了一遍，出现最多的是：Java、MySQL、Spring、SpringCloud、Golang、Python、Redis。没看错，**排第一的还是 Java**。所谓 AI Agent 开发，大部分长在传统后端功底上——Prompt 工程只是最上面那层皮，地基还是那套分布式、微服务、MySQL 调优。

**第三个：凉的只是中级。** 经验要求分布里，5-10 年拿走 49% 的岗位，1-3 年和 3-5 年各只有 12%。3-5 年这个区间最惨：上一档在往下挤，下一档够不着。我那位前同事刚好 4 年经验，数据把他的处境解释得明明白白。

## 给同行的 3 条实在建议

**1. 在 Boss 上搜岗位，关键词本身就在帮你筛薪资。** 同样的技能栈，挂在「AI Agent」下面和挂在「Java」下面，是两个薪资带。别只搜自己最熟的那个词。

**2. 5 年以内的简历，别硬刚 AI Agent 高薪岗。** 这批岗位普遍要求独立设计过 Agent 架构，投了也是陪跑。更划算的做法是对照 JD 里的技能词频改简历——这也是我接下来要做简历匹配工具的原因。

**3. 换语言不如加一层。** Go 岗中位 20K，只比 Java 高 3K，岗位量还一样。与其赌一门新语言，不如在现有技能栈上叠 AI 应用层——数据是站在这一边的。

## 这事会持续做下去

采集器、聚合脚本都在一个新仓库里（还在私有孵化，稳定了会开源）。接下来每周扫一轮，把「岗位热度、薪资水位、技能词频」做成周报——失业的同行需要，没失业的更需要提前知道风往哪吹。我自己就是那个「还没失业但想提前准备」的人。

数据管线里有个我比较得意的小原则：**入库只存聚合统计，公司名全部脱敏**。扫数据是为了看趋势，不是为了倒卖岗位信息，边界得自己先守好。

中间还踩了个哭笑不得的坑：调试端口 9222 死活连不上，排查半天发现是我自己天天开着的 Chrome 把端口占了。程序员的困境大抵如此——拦住你的往往不是技术，是你自己的电脑。
