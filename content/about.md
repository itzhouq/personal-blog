# 关于我

你好，我是 **搞副业的老周 itzhouq** 👋

一个普通的 10 年后端程序员：湖北农村出来，双非石油专业自学编程转行，现在人在上海——白天写代码，晚上带娃，剩下的时间用 AI Agent 折腾副业。

副业这条路我摔过很多跟头，试过的项目一只手数不过来。这次选择把一切摊开：**做的东西、流量数据、赚没赚到钱，全部公开，失败了也发。** 不是因为我成功了，而是失败的过程本身就有参考价值。

## 这里有什么

- **项目实况**：博客、工具站、开源项目的 build in public，从想法到上线的全过程和代码全公开；
- **赚钱实验复盘**：每个副业尝试的真实数据——收录曲线、流量截图、收入（哪怕是 0），周五周报连载；
- **AI Agent 工作流**：一个普通人怎么用 AI Agent 把"想都不敢想"的事变成"周末就能上线"，实测、提示词、踩坑都写下来；
- **活人故事**：副业失败史、新手宝爸的时间管理、农村到上海的这十几年。

这里没有成功学，全是普通人折腾出来的一手经验。
