# 出海自查清单（v1 · 2026-10）

给准备做出海内容站的你：从零到能收钱，四个阶段各查一遍。
每条都是实操中踩过坑之后沉淀的，照着勾就行。

## 一、域名与托管

- [ ] 域名后缀优先 .com / .net / .cn（别碰廉价后缀，部分广告平台会另眼相看）
- [ ] 托管用 Cloudflare Pages（静态站）或 Workers（带后端），免费额度足够个人站用一年
- [ ] DNS 托管在 Cloudflare：CDN、HTTPS、DDoS 防护全免
- [ ] 网站三件套齐全：关于页（真人信息）、联系页（有效邮箱）、隐私政策页
- [ ] HTTPS 强制跳转，多余的老域名 301 到主域

## 二、SEO 与数据

- [ ] Google Search Console 已验证，sitemap 已提交
- [ ] 新页面发布即手动请求收录（别干等爬虫）
- [ ] 接入 Cloudflare Web Analytics（免费零维护）或 umami，至少有一个渠道看 UV/PV
- [ ] 每篇文章有独立的 title / description / canonical
- [ ] 内链：新文章至少链 2 篇站内旧文（别链到未发布的草稿）

## 三、内容质量（AdSense 前置自查）

- [ ] 首屏是内容不是广告位堆砌
- [ ] 文章有真实信息量：原创实操 / 实测数据 / 独家整理，三者占一个
- [ ] 没有采集拼接的薄内容（重复度高、每篇两三百字的直接删或合并）
- [ ] 图片有 alt，无盗图（封面自己生成最稳）
- [ ] 分类和标签结构清晰，任何页面 3 次点击内能到首页

## 四、变现通道

- [ ] AdSense：申请前用 29 条官方要求逐条自查；被拒先改再提，24 小时内别重复提交
- [ ] 广告只投内容页，首页与列表页保持干净
- [ ] 永远不碰：盗版资源链接、破解软件分发、灰产工具推广——账号级封禁，全部站陪葬
- [ ] 备选广告网络（Adsterra 等）提前注册，别把鸡蛋放一个平台
- [ ] 收益数据每周回填一次台账（哪个渠道赚多少，心里要有账）
